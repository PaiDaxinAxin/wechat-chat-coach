## Remaining framework work

The requested single WeChat-like conversation is implemented and locally verified: counterpart/self messages occupy opposite sides, inline AI direction choices remain selectable, pending replies are editable, and supplementary profile/background/meeting/feedback forms open inside the thread. Day/night switching retains drafts. The direct-demo Chromium journey covers 390/320 px layouts, docked input, reload, keyboard menu/card focus and startup/session failure recovery, with zero paid calls. The retained invited-user HTTP journey also passes on the new UI.

Immutable per-case snapshots of the exact knowledge version, personal/counterpart context, conversation, selected direction, model suggestion and actual sent version remain a planned implementation item. Current persisted jobs/hashes and raw feedback receipts do not establish a complete immutable historical case. Do not describe this snapshot requirement as completed.

An explicit personal-style confirmation loop remains a planned implementation item so users can distinguish whether a reply fits them from whether the counterpart responded positively. The existing background/style/growth fields and outcome feedback are useful inputs, but are not yet that completed confirmation-and-learning loop. These two items were identified during the requirement audit; implementation is deferred while the owner prioritizes the conversation UI. Neither has a verified acceptance result at this stage.
